CLOUDPOWER Palette

Cloud Power Inc. Official Color System — ブランド・プロダクト・ドキュメント横断の統合カラー定義

📅 Version 2.0.0 🎨 Primary: #74B2E0 📚 参照: デジタル庁ダッシュボードデザインガイド

このパレットは、PowerPoint / Web UI / Power BI など CP の全成果物で使われる色を一元管理するためのデザインシステムです。各トークンは CSS 変数・SCSS 変数・JSON・Tailwind 設定として配布されます。

⚠️ Brand Gray #9E9E9F はロゴ専用です。UI の汎用グレーには Gray Scale（#888888 など）を使ってください。

Primary — CP Blue

ブランドカラー #74B2E0 を中心に 10 段階。50〜300 は背景・ボーダーに、400 が Primary（ブランド代表色）、500〜900 は文字・強調に。

Gray Scale

UI の汎用グレースケール。Body テキストは 700、ボーダーは 200、BG は 50/100 が基本。

Semantic Colors

状態を表す意味色。Base (500)、Light (300)、Dark (700)、BG (50) の 4 段階。

Do / Don't

✅ DoPrimary は #74B2E0（blue-400）のみを使う。他の青はサポート色
✅ Doロゴを扱うときは Brand Gray #9E9E9F を使う
✅ DoUI 汎用グレーは Gray Scale（#888888 など）を使う
✅ Doグラフは Chart Accent の順序（1→2→3...）で配色する
❌ Don'tロゴカラーと UI グレーを混同しない（#9E9E9F と #888888 は別物）
❌ Don't独自に類似色を作って使わない（テーマ一貫性が崩れる）
❌ Don'tPPTX で srgbClr 直指定を多用しない（テーマ変更が反映されない）

Developer

実装に組み込むためのコードスニペット。タブから言語を選んでコピーしてください。

:root {
  --cp-primary: #74B2E0;
  --cp-blue-50:  #F2F8FC;
  --cp-blue-400: #74B2E0;
  --cp-blue-700: #2E6BA6;
  --cp-blue-900: #1A3A5C;

  --cp-gray-700: #4A4A4A;  /* body text */

  --cp-success-500: #28A745;
  --cp-warning-500: #F0AD00;
  --cp-error-500:   #DC3545;
}
/* 全量は tokens.css を参照 */
{
  "colors": {
    "primary": { "400": "#74B2E0", "700": "#2E6BA6", "900": "#1A3A5C" },
    "chart": {
      "1": "#74B2E0", "2": "#2E6BA6", "3": "#5BBFB5", "4": "#F0AD00",
      "5": "#D4885C", "6": "#6B8FA3", "7": "#3D8B4A", "8": "#7A98AE"
    }
  }
}
// 全量は tokens.json を参照
$cp-primary: #74B2E0;
$cp-blue-400: #74B2E0;
$cp-blue-700: #2E6BA6;
$cp-gray-700: #4A4A4A;

$cp-chart: (
  1: #74B2E0, 2: #2E6BA6, 3: #5BBFB5, 4: #F0AD00,
  5: #D4885C, 6: #6B8FA3, 7: #3D8B4A, 8: #7A98AE
);
// 全量は tokens.scss を参照
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          400: '#74B2E0',
          700: '#2E6BA6',
          DEFAULT: '#74B2E0'
        }
      }
    }
  }
};
// 全量は tailwind.config.js を参照
