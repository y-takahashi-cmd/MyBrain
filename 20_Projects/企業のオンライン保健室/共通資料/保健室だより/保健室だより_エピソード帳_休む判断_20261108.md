# 保健室だより エピソード帳：「休む判断」シリーズ（2026-11-08 由香さんから聞き取り）

> 目的：体調が悪いのに無理して現場に出る人を減らす。本人が自分で判断して自分で上司に伝える意識改革（保健室が代わりに伝えない）。
> 「休む判断も、仕事のうち」はメール・だよりに入れず、社長に言ってもらう言葉として経営者に渡す（11/7決定）。
> 書くときの注意：会社名・個人名・業種・時期・病名は特定できないようぼかす／「休んでいれば助かった」等の医学的な因果は言い切らない（診断はしない理念）

## 1. 隠して出勤 → 取引先でクラスター
インフルエンザ・コロナを隠してお客様の会社へ行き、その会社でクラスターが起きた。非常に迷惑をかけた。本人は今も「あれが原因」と思いながら正直に言えずにいる。
→ テーマ：周りを守るための休む判断

## 2. 休みますと言えず → 検査時にはがん末期（3人）
体調が悪いのに「休みます」と言えず、検査を受けた時にはがん末期で亡くなった方を3人知っている。2人は看護師時代の同僚。由香さんが「代わりに出勤するよ」と声をかけたが、「上司がいい顔をしないから」「検査ではなんともないと言われたから」とがんばってしまった。もう1人はクライアントさん（守秘のため使う場合は要確認）。
※11/8 由香さん補足：厳密にはクライアントになる前の相談の方。「もう私のセッションではないから病院へ行きなさい」と伝えた。すでに亡くなっている。由香さんは「使わせていただいてもいいと思っている」（迷いあり）。
→ ゆっちぃ案：詳しく書くのは同僚2人だけ。クライアントさんは「私が知っているだけでも〜3人います」と人数に含めるだけ（守秘＋「保健室に相談しても助からなかった」と読まれるのを防ぐ）。由香さんの返事待ち
→ テーマ：自分を守るための休む判断

## 3. 保健室で決めて動いたら、いつの間にか解決（良い例）
「今しんどい」→ 問診票で不足の栄養素・生活習慣・自分が情熱をかけられている時などを一つ一つ見直し、チャレンジする。「なんで悩んでたんだろう？」になる。保健室で話して「これをやってみる」と自分で決めたことで、いつの間にか解決し、次に来たときには「そういえばそんなことで悩んでましたね」になるケースが多い。
→ テーマ：保健室の使い方（依存ではなく、自分で決めて動く）

## 4. 社長の一言で、社員がものを言えなくなった
社長が「そんなんだったらもう来なくていい」と言った瞬間、社員は安全性が守られないので、アイディアも思ったことも言えなくなった、と保健室で話すようになった。
→ テーマ：心理的安全性（経営者向け）。該当の会社には出さない

## 5. めまい・嘔吐を我慢 → 半年後にステージ4
メニエールの診断を受け、めまい・嘔吐を我慢して働いていた。メニエールの直前にがん検診を受けて問題なしだったが、半年後にステージ4の悪性進行がんが見つかった。**由香さんご自身の経験**（11/8確認）。自身の体（メニエール・がん）の経験を動機として語ることは可（メモリuser_profile_takahashi）。※ご主人の件はプレゼン等で使わない
【診断時の医師の一言（11/8 由香さん）】「あなたは看護師だから言うよ。自分で自分の自己免疫力・自己回復力を下げているのは自分自身だよ。患者のことばかりやっていないで、自分の事を考えなさい」→ 言われて初めて「マインドセットが必要なんだ」と思った。
→ テーマ：自分を守る／「検査で大丈夫だった」で体のサインを無視しない／保健室（自分で決めて動く）の原点
→ 注意：医師が由香さんに向けた言葉として書く。一般論にすると「病気は本人のせい」と読まれる
