# 企業のオンライン保健室　ストレスチェック導入・運用管理システム

サブタイトル：決定事項・予定日・実施日・担当者・確認結果を一元管理

**位置づけ：** けんけん（大関謙吾さんのClaude Code）が開発中のWebシステム「kokorocare」（Next.js＋Prisma＋Azure SQL）に追加実装する、法定ストレスチェック機能（57／23項目）の要件定義書。既存の7項目ウェルネス版（社員コンディションチェックアプリ、`ストレスチェックアプリ/`フォルダ）とは別物であり、システム上フラグで明確に分離すること。

**版：** v0.1（たたき台・由香さんの確認前）
**作成日：** 2026-07-20
**参照資料：** ストレスチェック研修資料1〜3（クライシス・カウンセリング協会）、法定SC運用マニュアル_v1.0.pdf、由香さんとの料金体系ヒアリング（2026-07-20）

---

## 0. このドキュメントの位置づけ

けんけんに渡した開発プロンプト（41項目・第1〜28章構成の要件定義プロンプト）を土台に、①研修資料3点（計185ページ）との突き合わせで見つかった不足・訂正点、②由香さんとの料金体系ヒアリングで確定した契約プランの具体的数値、を反映した「たたき台」です。プロンプトの開発の進め方（第40章）に沿い、コードを書く前段階として以下15項目を提示します。

**今回のスコープに含めないもの（由香さん確定・2026-07-20）：**
- 職場復帰支援、治療と仕事の両立支援
- 具体的な職場環境改善計画・管理職研修・セルフケア研修・効果測定（次段階モジュール）

## 1. 要件定義書

### 1-1. システムが兼ねるもの（プロンプト原文どおり）
導入時の運用決定書／実施体制確認書／年間スケジュール／実施準備チェックリスト／実施記録／通知履歴／受検状況管理／高ストレス者対応管理／医師面接指導管理／保健室面談管理／会社報告管理／行政報告管理／情報保存台帳／苦情・問い合わせ管理／翌年度への引継ぎ資料

### 1-2. 開発範囲
ストレスチェックの導入準備〜実施後評価まで。集団分析結果を用いた具体的な職場環境改善計画・施策・研修・効果測定は次段階の別モジュール。

### 1-3. 基本原則（全チェック・確認・実施項目の共通入力欄）
項目名／項目の説明／法令上の区分／必須または任意／担当区分／実行担当者／最終確認者／予定日／実施日／確認予定日／確認日／ステータス／確認結果／決定内容／実施内容／対応結果／添付資料／根拠資料／備考／最終更新日時／更新者

**法令上の区分：** 法令上必要／指針上望ましい／努力義務／会社運用ルール／企業のオンライン保健室運用ルール／契約上必要／確認中／対象外

**ステータス：** 未確認／確認中／未決定／決定待ち／未着手／準備中／実施中／確認待ち／完了／保留／対象外／要対応／期限超過（予定日超過で自動表示）

一項目に複数回の通知・対応がある場合は履歴として複数登録。予定日と実施日、確認日と実施日は別項目として保存。

### 1-4. 実施目的（複数選択）
法令対応／社員のセルフケア／メンタルヘルス不調の一次予防／高ストレス者の早期発見／医師面接指導への接続／職場環境改善／離職・休職予防／健康経営／会社の課題把握／その他（自由記載）

## 2. 用語一覧（プロンプト原文の用語集＋今回の追加・訂正）

プロンプト第3章の用語集（事業者／会社責任者／制度実施責任者／会社管理者／会社担当者／ストレスチェック実務担当者／実施者／実施代表者／共同実施者／実施事務従事者／受検者／面接指導対象者／高ストレス者／医師による面接指導／面接指導医／産業医／企業のオンライン保健室担当者／保健室面談／ストレスチェックシステム（管理者）／実施者登録システム／受検状況／個人結果／集団分析／衛生委員会等／労働者代表／本人同意／受検勧奨／不利益取扱い／職場環境改善）は基本的にそのまま採用。以下を追加・訂正する。

| 用語 | 説明 | 出典・要確認 |
|---|---|---|
| **実施の管理者**（追加） | 人事権を持たず個人結果も扱わないが、実施の管理業務（日程調整・進捗確認等）を担う役割。会社管理者・実施事務従事者とは別区分。プランに応じて設置有無が変わる | 研修資料2 p18。用語集に第三の役割として追加要 |
| **監督的地位にある者**（追加） | 受検労働者について解雇・昇進・異動に関する直接の権限を持つ者。実施の事務（実施事務従事者）に従事してはならない | 研修資料1（安衛則52条の10②）。実施事務従事者の選任チェックに除外ルールとして反映要 |
| **ホルモンバランスチェック**（追加・当社独自） | 法定ストレスチェックとは別建ての、プレミアムプラン独自オプション健康チェック。ストレスチェック年1回＋本チェック年1回、または、ストレスチェック年2回、を選択制 | 由香さんヒアリング。法令上の位置づけはなし＝当社独自サービスとして用語集に明記 |
| **産業医仲介**（追加・当社独自） | 法定の医師面接指導が必要になった際、当社が産業医を手配・取次ぐ行為。仲介手数料が発生する | 由香さんヒアリング |
| **調査票（57項目版／80項目版）**（追加） | 職業性ストレス簡易調査票の型。プロンプトは調査票の型を項目化していなかったため追加 | 研修資料2 p22 |

## 7. データベーステーブル案（主要テーブルのみ・抜粋）

- `companies`（企業基本情報）／`worksites`（事業場）
- `contracts`（契約：プラン種別・契約期間・初期費用・従量単価）
- `plan_options`（オプション：チャット相談・保健室便り・産業医仲介 等、企業ごとON/OFF）
- `plan_toggles`（**プランごとの「含む／オプション」チェック管理**：集団分析・会社向け報告書・Zoom報告会をプラン別にBoolean管理。固定ルール化せず企業単位で個別設定可能にする＝由香さん確定要件）
- `roles_assignments`（役割ごとの担当者・就任日・守秘義務説明日）
- `schedule_items`（年間スケジュール39項目：予定日・実施日・担当・ステータス）
- `sc_rounds`（実施回：企業×年度、調査票タイプ＝57項目/80項目/23項目、実施期間）
- `targets`（対象者：区分・対象/対象外・登録状況）
- `attendance_status`（**受検状況専用**。回答内容を含まない）
- `personal_results`（**個人結果専用・暗号化**。回答内容・点数・評価結果・高ストレス該当。`attendance_status`とは別テーブル・別権限で厳格分離）
- `high_stress_flags`（高ストレス者選定：実施者の最終承認フラグ必須。システム自動判定は`candidate`、実施者確定後`confirmed`のステータス遷移を持つ）
- `judgement_versions`（判定ロジックのバージョン管理：素点法/換算点法、基準改定履歴）
- `interview_records`（補足的面談／生活習慣指導／産業医仲介面談を統合管理する面談テーブル。`session_type`で種別を区別し、企業の**プラン内無料枠消化数**を`sc_rounds`単位で集計できるようにする）
- `doctor_referrals`（産業医仲介：仲介手数料15,000円/事例の請求管理。`interview_records`の枠消化とも連動）
- `consents`（本人同意：同意種別・目的・提供先・撤回）
- `company_reports` / `admin_reports`（会社向け報告／行政報告）
- `retention_ledger`（情報保存台帳：保存対象ごとの保存期間・廃棄予定日）
- `complaints`（苦情・問い合わせ）
- `emergency_events`（緊急対応：[[feedback_emergency_escalation]]と連動し、危険信号検知時は由香さんへの通知フローをトリガー）
- `audit_logs`（全操作履歴）
- `terminology`（用語集：管理画面から編集可能）

## 8. 主要な業務フロー（概要）

```
契約締結（プラン・オプション確定）
 → キックオフ・実施体制決定（実施の管理者の設置要否を含む）
 → 衛生委員会等審議 → 実施規程作成・承認
 → システム準備（管理者システム／実施者登録システム）
 → 対象者名簿作成・登録（監督的地位者を実施事務従事者から除外）
 → 社員周知
 → 受検開始 → 中間・終了前リマインド → 受検終了
 → 個人結果通知（実施者→本人へ直接）
 → 高ストレス者選定（システム候補判定 → 実施者が最終確認・確定）
 → 高ストレス者本人案内（面接指導／保健室面談／両方／希望しない、を選択）
   ├─ 医師面接指導希望 → 産業医仲介（プラン内無料枠 or 都度課金）→ 面接指導 → 医師意見聴取 → 会社が就業上の措置検討
   └─ 保健室面談希望 → 補足的面談 → （必要に応じ）生活習慣見直し面談・産業医面談への繋ぎ
 → 集団分析（10人未満は原則不可・全員同意時のみ例外）
 → 会社向け実施状況報告／最終報告
 → 行政報告（様式第六号の二・対象は常時50人以上の事業場が中心、確定は最新法令で要確認）
 → 実施後評価
 → 職場環境改善への引継ぎ（次段階モジュールへ・今回は情報保存のみ）
```

## 9. ステータス遷移（例：高ストレス者選定）

```
未着手 → 準備中（選定基準会社説明）→ 実施中（補足的面談等）
  → 確認待ち（システム候補判定＝candidate）
  → 完了（実施者確定＝confirmed）
  ※予定日超過で自動的に「期限超過」表示
  ※「保留」「対象外」「要対応」は各段階で選択可能
```

同様のパターンを面接指導・保健室面談・行政報告等の各フローに適用。

## 10. 受検状況と個人結果の分離方法

- **テーブルレベル**：`attendance_status`（受検状況）と`personal_results`（個人結果）を別テーブルとし、外部キー以外の直接JOINを禁止するアクセス層を設ける
- **画面レベル**：受検状況管理画面（#14）と個人結果管理画面（#15）を別画面とし、URLレベルでも権限チェックを分離
- **権限レベル**：会社管理者ロールには`personal_results`テーブルへのSELECT権限自体を付与しない（画面非表示だけでなくAPIレベルで遮断）
- **監査ログ**：`personal_results`への閲覧は「個人情報閲覧」として全件監査ログに記録

## 12. 法令上確認が必要な項目（研修資料で確定値が判明したもの／要最新法令確認のもの）

**確定値として初期設定に反映してよいもの（研修資料1・2・3より。ただし年度改定は都度要確認）**
- 常時50人以上の事業場：ストレスチェック実施義務／50人未満：努力義務
- 検査結果等報告書：様式第六号の二（労基署提出）
- 記録の法定保存期間：5年間（検査結果・面接指導結果）
- 監督的地位にある者は実施事務従事者になれない
- 集団分析：10人未満は原則不可（全員同意時のみ例外）
- 労基署報告に高ストレス者数は含めない
- 就業上の措置：通常勤務／就業制限／要休業の3区分
- 調査票タイプ：57項目版／80項目版

**専門家確認・法令最新版確認が必要なもの**
- 上記数値・様式は年度改定の可能性があるため、実施年度ごとに最新の厚労省指針を確認する運用にする
- 行政報告の対象事業場・提出期限の細目
- 少人数集団分析の同意取得方法の細目

## 13. 個人情報管理上のリスク

- `personal_results`テーブルの暗号化・アクセス制御が破られた場合、高ストレス該当という機微な健康情報が漏えいするリスク→暗号化・監査ログ・権限分離の三重対策が必須
- 会社管理者に「実施の管理者」等の近い役職が増えることで、権限設計を誤ると個人結果へのアクセスが実質的に会社側に漏れるリスク→ロールごとのテーブルレベル権限を厳格にテストする
- プレミアムの面談枠消化管理（`interview_records`）は、誰が・何回・どの企業の枠を使ったかという情報自体は課金目的で会社にも見える必要があるが、面談の**内容**は見せてはならない→枠消化数（件数）と面談内容（テキスト）を別テーブルに分離する
- 産業医仲介の請求管理（`doctor_referrals`）に、仲介対象者の氏名を含めると経理担当者等に高ストレス該当が伝わるリスク→請求書は「1件」単位の匿名化した件数ベースで発行する運用にする

## 16. 契約プラン管理（確定料金体系・2026-07-20ヒアリング反映）

### 基本プラン
| プラン | 内容 | 単価×人数/年 | 初期費用 |
|---|---|---|---|
| ライト | 自社運営（システム貸与のみ） | 2,600円×人数 | 50,000円 |
| スタンダード | 丸投げ・ストレスチェックのみ | 5,400円×人数 | 50,000円 |
| プレミアム | 丸投げ＋産業医連携＋面談・相談まで（推奨プラン） | 14,400円×人数 | 50,000円 |

プレミアムの実施回数：ストレスチェック年1回＋ホルモンバランスチェック年1回、または、ストレスチェック年2回、を選択制

### プレミアム内 無料枠
- **10人あたり年間6回まで無料**。対象：補足的面談／生活習慣見直し面談／産業医面談への繋ぎ（産業医仲介手数料を含む）／介護相談等の希望相談／会社担当者からの「対応要否」相談／本人からの「医師の指導後どうすればよいか」相談
- 根拠：実績上10人中3〜5人程度が面談を要し、補足的面談→産業医面談で2回分、その後の生活習慣見直し面談も必要になるケースが多いため
- 保健室たよりはプレミアムに標準で含む
- 枠を使い切った後の追加分はすべて都度課金（下表）

### ライト・スタンダードの扱い
面談枠は標準では付属しない。契約後にオプションとして追加購入可能な設計とする。

### 都度課金・オプション単価（共通）
| 項目 | 単価 |
|---|---|
| 補足的面談 | 15,000円/60分 |
| 保健室生活指導・相談 | 15,000円/60分 |
| 産業医仲介手数料 | 15,000円/事例（プレミアム無料枠内は無料、枠超過分から発生） |
| チャット相談（会社契約・窓口は会社担当者） | 10,000円/月 |
| チャット相談（個人契約） | 10,000円/月 |
| 保健室便り（ライト・スタンダード向け） | 1,000円/月（年間12,000円） |

### 費用負担の切り分け
- 法定業務（実施・集団分析・行政報告等）およびプラン内無料枠内の補足的面談等：**会社負担**
- プラン内無料枠を超えた分、個人希望のチャット相談等の任意サービス：**個人負担**、または契約時に会社が「全額会社負担／個人負担／折半」を選べる

### 運用アドバイス（提案書・手順書に反映）
- 補助金活用を想定する会社には、契約時に追加プランの設定を推奨
- 定期的に面談を受ける人をあらかじめ選出しておくことを推奨
