### 由香さんが「見ても分からなかった」理由（ゆっちぃの見立て）

1. **「集団分析の報告書」の実物が1枚も載っていない**：「部署ごとの傾向」と言葉で書いてあるだけで、どんな紙が出てくるのかが見えない。お客様が一番知りたいところが抜けている
2. **「制度・法律」の説明が中心**：6ページのうち半分くらいが「見せない理由」「法律」の話。正しい内容だが、「で、何が楽になるの？」に答えていない
3. **紙のやり方との比較がない**：紙でやっている会社には、「今の作業がどう変わるか」が一番響くのに、それが書かれていない
4. **字が多い**：1ページに説明文がぎっしり

→ ガイドは「導入が決まった会社のご担当者」向けで、**営業（検討中の会社）向けではない**。だから中身は正しいけれど、刺さらない。

### 実物とのくい違い（要確認）

- ガイド5ページ・パンフレットには「**部署ごと・年代ごと**の傾向」とある。でも実際の報告書（`Downloads\集団分析報告書.pdf`）には**部署ごとしか出ない**（年代別の表はない）。パンフレットは「部署ごと」に直し済み。ガイドの方は大関さんに伝えるかどうか、由香さんの判断
- ライトプランの実施者の問題：ガイド4ページに「会社のご担当者には資格の付与そのものを行っていません」「個人の結果を取り扱うのは当社の有資格スタッフのみ」とある。→ **ライトでも個人の結果を確認するのは保健室側**、という作りで合っているか、由香さんに確認したい

## 作る資料（案）：「紙からアプリへ｜集団分析はこう出てきます」A4・2ページ

### 1ページ目：実際に出てくる報告書（見本）
- 今の `集団分析の見本_v0.1.pdf` をそのまま使う（実物と同じ1〜5の項目・数字は架空）

### 2ページ目：紙のときと、何が変わるか

**① 作業の比べっこ（左に紙・右にアプリ）**

| | 紙のとき | アプリのとき |
|---|---|---|
| 配る・集める | 印刷して配布、封筒で回収 | メールで一斉配信、スマホで回答 |
| 点数を出す | 手で入力して計算 | 回答と同時に自動で採点 |
| 高ストレスの判定 | 基準表を見て一人ずつ | 自動で判定 → 有資格者が確認 |
| 集団分析 | 部署ごとに集計して、判定図を作る（または業者に出して待つ） | **確認が終われば、報告書（PDF）がすぐ出る** |
| 保管 | 紙を5年間、鍵付きで保管 | システム内に保管（会社の画面からは見えない） |

**② 報告書の見方（1〜5を一言ずつ）**

| 項目 | ここを見る |
|---|---|
| 1. 部署別 高ストレス者の状況 | 高ストレスの人が多い部署はどこか |
| 2. 仕事のストレス判定図 | 点が右下（オレンジの線の側）にあるほど要注意 |
| 3. 健康リスク | 100が全国平均。**120を超えたら**手を打つ目安 |
| 4. 4尺度の比較 | 「仕事の量」「自分で決められるか」「上司の支え」「同僚の支え」のどれが原因か |
| 5. SPQ | 体調のせいで、本来の力がどれだけ出せていないか（％） |

**③ 知っておいてほしいこと（3つだけ）**
- 10人未満の部署は表示されません（だれの回答か分かってしまうため）。部署をまとめれば出せます
- 個人の回答・点数・だれが高ストレスかは、報告書に入りません
- 報告書は安全衛生委員会の資料にそのまま使えます

### 入れないもの
- 毎月・毎週の質問の文面（パクられる）
- 定期チェックの話、プラン、料金
- 「保健室からの読み取り」のような、実物にないもの
