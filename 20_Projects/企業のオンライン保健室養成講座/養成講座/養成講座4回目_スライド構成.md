- S12: ヒーリングプロトコル：エネルギーによる身体への介入（脳・身体の図）
- S13: 人間のすべての行動起点は「論理」ではなく「感情」である（脳科学の図・日本人約40%が感情的に行動）
- S14: 感情・理性・理論のアンバランスが引き起こす「真」（3つがバランスよく働いて初めて、心は安定する）

- S17: 脳のOSバグ③：過去の「強い思い（トラウマ）」に引っ張られる
- S18: 「普通の基準は人それぞれ」：ポジティブとネガティブの本当の違い（Negative: 問題面をはっきり見る / Positive: 問題をはっきりできる）

### 4つの脳タイプ（24〜36）
- S24: 自分を知り、他者を生かす「4つの脳タイプ」（思考・行動・感覚・直感の4タイプ）
- S25: STEP 1: あなたの「脳の窓」を診断する（I. 脳への入力（インプット脳）/ II. 脳外み（アウトプット脳）・あなたの組み合わせを覚えて次のページへ）
- S26: 脳タイプ別 性格診断（4つのカラー別・脳タイプ表）
- S27: 指と脳の組み方でわかる4つの思考パターン（【右脳】Ro / 【右脳】Re / 【左脳】Gi / 【左脳】Gu）
- S28: 勇（Yu）- 可能性を悦ぶ開拓者（1%の可能性があるなら動く・CHARACTERISTICS・BAD LOOP・HIGH PERFORMANCE）
- S29: 誠（Sei）- 価値を重んじる実直者（70〜80%の確算が見えてから動く・CHARACTERISTICS）
- S30: 義（Gi）- 善いことをよろこぶ共奏者（0%または100%（ゼロなら徹底的に）・CHARACTERISTICS）
- S31: 礼（Rei）- 一体感を歓ぶ共鳴者（50%「みんなでやろう」・CHARACTERISTICS）
- S32: 「喜び」と「存在意義」の決定的な違い（内側（利用）のために vs 社会のために）
- S33: 何によって「自由」を感じるか？（ストレスの源泉）（「制御できることが増える」/ 「納得する」/ 「もてる」/ 脳タイプによって異なる「不満」の表現方法）
- S34: 会話のテーマと行動のスイッチ（Task Focused / People/Emotion Focused・行動の基準）
- S35: チームにおける「立ち位置」の違い（円グラフ・内側・外側）
- S36: 4つの「バッドループ」回避マニュアル

### NLP・認知科学（43〜56）
- S43: NLPと脳科学：認知のフィルターが変わると行動変容が起こる理由
- S44: 現実は変えられない、しかし「認知」は変えられる（NLPが認知のプログラムを変える・認知→感情→行動「変化の鍵」は認知を変えること）
- S45: 思考と言葉で行動をハックする「NLP」の3要素（Neuro（神経体活動）/ Linguistic（言語）/ Programming）
- S46: 一般的な心理学とは一線を画す3つの特質性（1. 変化・結果重視 / 2. 問題固定化を防ぐ・認知の再構成 / 3. 新しい行動パターンを強化する）
- S47: 人が行動を起こし、結果を生み出すための5つのプロセス（NLPのアプローチ）
- S48: 意味づけのわずかな違いが、人生の軌道を完全に分ける（人生に適応）
- S49: 心理的プロセスを裏付ける「脳科学」との完全な一致（大脳辺縁系・前頭前野・NLPは「思考の構造をハックするアプローチ」）
- S50: なぜ意味づけが変わるのか？脳のフィルター「RAS」と「スコトーマ」（RAS（情報体活動）・スコトーマ（心理的盲点））
- S51: 人生を再プログラミングするNLPの4つの主要テーマ（①思考パターンの変容 / ②感情のコントロール / ③コミュニケーション / ④無意識パターンのコピー）
- S52: 実践技術①：リフレーミング（意味の枠組みの書き換え）（コンテキストリフレーミング・コンテンツリフレーミング）
- S53: 実践技術②：アンカリング（固定的感情スイッチの作成）（Step1: 初期化 → Step2: ピーク体験を感じる → Step3: アンカーを打つ → Step4: アンカーを発火させる）
- S54: 脳の構造を利用した、その他の強力なツール群（モデリング（成長のコピー）・サブモダリティ（主観的意識の変化））
- S55: 「最後の行動変容プログラム」を生み出すシナジー方程式（NLP × [関係] × [スコトーマ] × [RAS] = 行動変容プログラム）
- S56: 脳と言葉を再プログラミングし、望む結果を自ら創り出す

### NLP×コミュニケーション・VAK（57〜72）
- S57: 人生を再プログラミングするNLPの4つの主要テーマ（「コミュニケーション」に注目）
- S58: コミュニケーション技術としてのNLP
- S59: 「この写真を見て、どう感じますか？」（夕日の写真・ワーク）
- S60: V（Visual）視覚の感覚例（「波の音がする感じ」「静かな感じ」「夕方の感じ」「彩色が綺麗」「気持ちよさそう」「高さを感じる」「涼しい感じ」「砂が温かそう」）
- S61: 「この写真を見て、どう感じますか？」（焚き火の写真・ワーク）
- S62: （視覚 → 火 / 聴覚 → パチパチ音 / 体感 → 温かい）
- S63: V A K とは（導入スライド）
- S64: VAKをものにしよう：五感で組むコミュニケーションの概念（信頼をつながる質問をつくり、人生を変える「信頼感」攻略プレイブック）
- S65: 伝わらない理由は「感覚」のズレにある（A比率・K比率・V比率のバランス）
- S66: V（Visual）視覚優位タイプ：未来のイメージを描く（見た目と「結論」を最も重視する。日本人3割）
- S67: A（Auditory）聴覚優位タイプ：論理と響きを重んじる（論理・数字・言葉の響きと「結論」を重視する。日本人1割）
- S68: K（Kinesthetic）身体感覚優位タイプ：心よさと論感を知る（論理よりも「感触」と「心よさ」を重視する）
- S69: 実践：お二人でマウスを育ててください（VをV表で / AをA表で / KをK表で）
- S70: VAKSの会話術：相手に「強く」伝えるテスト（感情的に実感を与えながら具体的に一致行動を促す）
- S71: 相手の心を開く！VAK別「信頼感」の作り方（Vタイプ向け / Aタイプ向け / Kタイプ向け）
- S72: 鋸がちな罠：仕事と私生活の「VAKの落差」（仕事モードと私生活で異なる言語を使う傾向）
