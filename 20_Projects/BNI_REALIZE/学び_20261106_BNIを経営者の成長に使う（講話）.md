## 1. 講師の実績（BNIの活用度）
- 9年前は自宅で一人、月の売上12万円 → 今は約15人の事務所
- 10月時点の売上 約6,300万円。年会費12万円の約500倍が返ってきている
- 「売上をもう一桁上げるにはどうするか」という視点で聞くと、50分が浪費から投資に変わる

## 2. BNIの一番の可能性＝経営者としての成長
- 企業の目的は**顧客の創造**（ドラッカー）
- そのために経営者がやることは2つ
  - **マーケティング**＝お客さんのニーズを知ること
  - **イノベーション**＝満足を届けること（ポケベルの例：10年後も同じ価値の商品はない）
- 問い：**経営者として、1週間・1ヶ月に何時間マーケティングの時間を取っているか？**

## 3. リファラルマーケティング＝ウィークリープレゼンを「市場調査」として聞く
- 大企業はマーケティング部・開発部・広告を持つ。中小企業は持てない → BNIでそれをやる
- メンバーのプレゼンには、その業界のニーズ・新しい技術が詰まっている
- 「自分の市場（講師なら社労士）でどう生かせるか」と考えながら聞く

## 4. 競争 → コラボレーション → **コ・クリエーション（共に新しいものを作る）**
- 事例：塗装業のメンバーの困りごと（雨どいの塗装）から、別のメンバーと新しい道具を開発 → 実用新案を申請中、業界最大手メーカーから取り扱いの連絡
- 事例：長崎の唐揚げ屋さんをメンバーの力で関西・東京へ広げた
- 大事なのは「市場は何を求めているか」「誰と組めば満足に変えられるか」「できたものを誰の力で広めるか」

## 5. 年会費12万円を「どのレベル」で使うか
- 地域（チャプター）／全国（約9,000人）／世界
- ただし**一番大事なのは自分のチャプター**。そこでの信頼があってこそ

## 6. 成長マトリクス（どこでBNIを使っているか）
| | 既存の市場 | 新しい市場 |
|---|---|---|
| 既存の商品 | 多くのメンバーはここだけ（ここも大事） | 例：講師は東京にオフィスを出した |
| 新しい商品 | 例：DiSC理論・人事評価制度を既存のお客様へ | コ・クリエーション |

- 1マスだけ＝25%。50%・75%に広げられる
- 人手不足の時代：講師は「人がやらなくていい仕事はAIに」と顧客に提案し、人に頼らない売上へ移している
