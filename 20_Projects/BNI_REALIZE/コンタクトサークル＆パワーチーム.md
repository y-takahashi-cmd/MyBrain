## パワーチーム（最も密接に連携し互いを積極紹介するコアグループ）

> **パワーチームとは：** 同一ターゲット（5〜49名規模の中小企業経営者）に
> 対して異なるサービスを提供し、互いに紹介しあうことで全員のビジネスが
> 回るグループ。コンタクトサークルよりも少人数・密度が高い。

### ▼ パワーチームA「健康経営チーム」（コア3名＋由香さん）

```
髙橋由香（企業のオンライン保健室）
  ← 心身の不調予防・早期ケア・健康管理

内藤志穂（未病47プロジェクト）
  ← 未病診断で不調の「予兆」を可視化

伊集院麻代（声紋分析・組織改善）
  ← 声から組織のストレス・離職リスクを可視化

廣瀬貴英（採用定着コーチング）
  ← 採用した人材を定着させるコーチング
```

**なぜこの4名か：**
- 入会のきっかけが内藤・伊集院の2名。すでに関係性の土台がある
- 「採用→定着→健康管理」と企業の人材課題を川上から川下まで一気通貫でカバー
- 4名全員が「5〜49名規模の中小企業経営者・人事」をターゲットにしている
- 互いのサービスが競合せず補完している

**紹介の流れ：**
- 廣瀬さん→採用後の定着段階で「体調不良・メンタルダウンを防ぐために由香さんの保健室を」
- 内藤さん→未病診断で企業に入った際「継続的な健康管理は由香さんの保健室と」
- 伊集院さん→組織分析後「個人の心身ケアは由香さんの保健室が入ると効果が続く」
- 由香さん→保健室の経営者に「採用で悩んでいるなら廣瀬さん・内藤さん・伊集院さんを」

### ▼ パワーチームB「中小企業の顧問チーム」（拡張版）

```
髙橋由香（企業のオンライン保健室）
中村茂男（社労士）← 労務・採用・就業規則
宗田雅史（税理士）← 財務・経営・節税 ✅121済
廣瀬貴英（採用定着コーチング）← 人材育成
小野誠之（M&A・事業承継）← 経営戦略・後継者問題
```

**なぜこの5名か：**
- 中小企業経営者が抱える課題（財務・労務・人材・健康・事業承継）を5名でまるごとカバー
- 社労士・税理士が経営者に最も信頼される「士業ポジション」であり、保健室の紹介力が高い
- 宗田さんはすでに121済み→最も話を進めやすい
