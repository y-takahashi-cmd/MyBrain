# 型：お金のブロックを外す単発セッション

2026-10-28 仁部あきえさん用に作ったパワポを、ほかの方にも使えるようにした型。

- 料金の目安：**90〜120分・30,000円**（由香さん 2026-10-28）。90分でやり切るのは、話のテンポが早い方でもぎりぎり。ゆっくりの方は3時間でも足りないことがある
- 仁部さん本人用：`../仁部あきえさん/20261028_仁部あきえさん_お金のブロック単発セッション.pptx`

## 使うときに入れ替えるところ

1. 表紙の「〇〇 さん」→ご本人の名前
2. 第1部の「幼少期のお金の記憶」のスライド：「＿＿＿＿」と「（事前に聞いたエピソードを入れる）」に、事前に聞いたご本人のお金のエピソードを入れる
3. ノート欄で「ご本人」「子どもの頃の話」となっているところは、必要ならご本人の話に合わせる

## 流れ（48枚）

- はじめに：表紙／今日の流れ／今日、大切にしたいこと（選べます・正解はありません・今日の目標＝一つ気づいて、一つ持ち帰る）
- 第1部 魂の傷を聴く：お悩み（1〜10）→ゴールデンエイジ（短く）→「子ども時代のことも聴かせていただいていいですか？」→幼少期→お金の記憶
- 第2部 頭の構造を知る：1本のお話（7場面・各スライドに「お金で言うと…」）
- ワーク（アートシフトワーク その18をベース）：穴埋め「お金とは、＿」「お金を受け取る私は、＿」→表に点数→一番邪魔している思い込み→場面に戻る→外から見る→相手の中にも入ってみる→理想のあなた→「あの時のあなたへ、＿」→これから選びたいお金の考え
- 【共有停止】のスライド2枚＝由香さん用の進め方メモ（そこで画面共有を止める）
- エネルギー → まとめ（1〜10の聞き直し・今日持ち帰るもの・次に同じ感情が出てきたら）→「根深いものは、何度も何度も自分に魔法をかけて、とっていく」→絶対的安心感 → ありがとうございました（1週間後にLINEで様子を伺う）

## 時間があるとき（90〜120分）に戻せるもの

90分版では時間が足りず外したもの：和解と許し（「相手の信念・価値観は、いつできた？」「相手は本当はどうしたかった？」）／理想の未来（大成功している自分の見える・色・聞こえる・体の感じ）。外したのは仁部さん版（2026-10-28）。
